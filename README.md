Game where you shoot slimes and try to survive for 5 waves. This is my 2nd project on making game and it's quite short because I don't have much time to develop it so this it the best effort I can come up with. All you got to do i this game is not to die to the slime until wave 5 ends, you gotta clear the wave first to advance to the next one and your objective is to finish wave 5 to win.
Control
Left click : Shoot
WASD: Movement
